# Proyecto-SuperTienda-PowerBI

Análisis de Ventas en Power BI: Exploración de Clientes, Productos y Rentabilidad
Este proyecto tiene como objetivo analizar el rendimiento comercial de una empresa mediante un dashboard interactivo desarrollado en Power BI, utilizando un conjunto de datos públicos provenientes de Kaggle. El análisis considera múltiples dimensiones del negocio, tales como clientes, productos, ubicación geográfica, métodos de envío y márgenes de ganancia.

El dashboard permite una exploración clara y dinámica de indicadores clave como ventas, cantidad vendida y utilidad, así como un desglose detallado por región, segmento de cliente y tipo de producto. Todo esto con un diseño optimizado para facilitar la toma de decisiones informadas a partir de datos.

Entre los datos analizados se incluyen columnas clave como:
Order Date, Ship Mode, Customer ID, Segment, Region, Product Name, Sales, Quantity y Profit.

Esto permitió identificar tendencias de comportamiento, productos de alto y bajo rendimiento, eficiencia en la distribución y zonas geográficas más rentables.

Desafíos del proyecto:
- ### Modelado y limpieza de datos:
  Uso de Power Query para transformar y depurar los datos, asegurando una estructura coherente y lista para el análisis.

- ### Optimización visual y técnica:
  Diseño de un dashboard compacto, priorizando los gráficos más relevantes según el espacio disponible, sin comprometer claridad ni funcionalidad.

- ### Buenas prácticas en DAX:
  Creación de una tabla dedicada exclusivamente a medidas para mantener el modelo organizado, escalable y fácil de mantener.
